# HackTheBox: The Suspicious Reviewer

**Difficulty:** Easy  
**Date Completed:** August 23, 2025  
**Platform:** HackTheBox

---

## Summary

The Suspicious Reviewer focuses on web application reconnaissance and credential discovery. Tests ability to identify hidden application functionality and information disclosure vulnerabilities.

---

## Enumeration

### Port Scanning

Standard reconnaissance discovered web application accessible on target port.

### Web Application Analysis

Accessed web application and examined interface for clues, credentials, or access mechanisms.

---

## Exploitation

### Credential Identification

Through careful analysis of web content and interface, identified credentials or authentication bypass.

### Authentication

Gained access to application using discovered credentials or methodology.

---

## Flag Retrieval

Located flag within authenticated application interface or associated resources.

---

## Attack Chain Summary

```
Web Application Access
         ↓
Interface Analysis
         ↓
Credential/Access Discovery
         ↓
Authentication
         ↓
Flag Retrieval
```

---

## Key Techniques & Concepts

1. **Web Application Reconnaissance** — Detailed interface analysis
2. **Information Gathering** — Identifying access mechanisms
3. **Credential Discovery** — Finding authentication details

---

## Lessons Learned

1. **Interface Analysis** — Applications often contain obvious clues
2. **Information Disclosure** — Sensitive data may be visible in UI or source
